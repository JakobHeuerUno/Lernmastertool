# Karteikarten

Eine Datei pro Thema oder Kapitel (z. B. `waermeleitung.md`). Format:

```
### wsu-0001 · thema: waermeleitung-ebene-wand · quelle: Skript S. 12
F: Wie lautet das Fourier-Gesetz (1D)?
B: $\dot q = -\lambda \frac{dT}{dx}$
Z: Minus, weil Wärme vom Warmen zum Kalten fließt.

### wsu-0002 · thema: waermeleitung-ebene-wand
C: Der Wärmeleitwiderstand einer ebenen Wand ist {{c1::$R = \frac{s}{\lambda A}$}}.
```

Nächste freie ID: `lern karten naechste-id`. IDs nie ändern oder wiederverwenden (Anki-Lernhistorie hängt daran).
